# Native Windows calls (port/src/win/)

What the game gets from the native layer. Unimplemented calls are stubs
that log their name once (`STUB()`) and return a neutral value.

| Area | Module | Implemented | Stubbed |
|---|---|---|---|
| Start-up | startup.c, main.c | GDI objects, built-in window classes, DGROUP image, INSPACE.EXE module, call of WinMain (renamed `inspace_WinMain`); `--keys` key injection for headless runs | |
| DGROUP | dgroup.c, game/globals.c | data segment 19 of INSPACE.EXE unpacked at run time (OPTLOADER LZ) into `dgroup[]`; plain globals are views of it (game.h); near pointers point into it; far pointers start zero | |
| NE files | ne.c | header, segments, OPTLOADER LZ, resource table lookup | relocation tails (not needed for DGROUP) |
| C runtime | crt.c | MSC `rand`/`srand` (LCG), `wsprintf` (16-bit `%d/%u/%x` unless `l`), `lstrcpy/cat/len/cmp`, `_dos_findfirst/next` (no volume labels), `stat`, `_getdrive/_chdrive` (drive C only) | `utime` |
| Memory | kernel.c | `GlobalAlloc/Lock/Unlock/ReAlloc/Free/Size/Compact` (native blocks, 25% slack for REC_70) | |
| Files | kernel.c | `OpenFile` (exist/read/write/create/delete), `_lread/_lwrite/_lclose/_filelength`; DOS paths: `C:\SPACE\` = data folder, `C:\WINDOWS\` = settings folder, case-insensitive lookup | other drives |

| GDI | gdi.c, draw.c | DCs (window DCs draw into the framebuffer, clipped to the client area inside the parents' and not under popups stacked above; `GetWindowDC`), 8-bit and monochrome bitmaps, `BitBlt/StretchBlt/PatBlt` with any ROP3 on palette indices, `FillRect/FrameRect/Rectangle/Polygon/Ellipse/LineTo/SetPixel/GetPixel/ScrollDC`, `DrawFocusRect` (dotted), brushes (solid, pattern; stock DKGRAY_BRUSH dithered), pens, regions as clip rectangles, palettes (`SelectPalette/RealizePalette` set the framebuffer palette, identity mapping; `CreatePalette`, `AnimatePalette` (PC_RESERVED entries, on screen when realized), `GetSystemPaletteEntries`), static system colours, LoadBitmap-style DIB conversion, `CreateDIBitmap` (DIB_PAL_COLORS, DIB_RGB_COLORS: nearest entry of the DC's palette) | dithering of other RGB brushes, stretch modes, wide pens |

| Dialogs, controls | dialog.c, controls.c, edit.c | `DialogBox` (modal loop, owner disabled), `CreateDialog`, `EndDialog`, `GetDlgItem`, `SendDlgItemMessage`, `IsDialogMessage` (Tab, arrows in groups, Enter for the default button, Esc, mnemonics); templates from resources with DS_SETFONT; classes Button (push buttons), Static (left/centre/right, word-wrapped, `&` prefixes), Edit (multi-line display; single-line editing: blinking caret, selection by keys and mouse, select-all on dialog focus, EM_GETSEL/SETSEL/LIMITTEXT, sideways scrolling, EN_ notifications), ComboBox (drop-down list: sorted, up to 256 items, keys, mouse, CBN_SELCHANGE, scroll bar when the list does not fit), drawn in Windows 3.1's look | check boxes, radio buttons, list boxes, scroll bar controls, edit clipboard/undo, multi-line editing, icon statics; messages with pointers in lParam (CB_ADDSTRING ...): native callers use `combo_*` (user.h) |
